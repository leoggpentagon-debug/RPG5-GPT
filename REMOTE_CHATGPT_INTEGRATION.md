# RPG5-GPT — актуальная удалённая передача JSON

Старая инструкция про Sign in with ChatGPT и одобрение OpenAI **не используется**. Вместо неё установлен канал передачи через подключённый Supabase.

## Схема

ChatGPT Plus → `rpg5_bridge.publish_packet` → `rpg5_bridge.packets` → Edge Function `rpg5-packet-bridge` → GitHub Pages.

- Записывается исходный текст **полного JSON-пакета**, не краткий пересказ.
- SHA-256 рассчитывается в PostgreSQL и проверяется браузером.
- Edge Function только читает JSON; не меняет игровой канон.
- Домашний компьютер не нужен как сервер, платный OpenAI API не используется.

## Авторизация

Браузер получает JWT от Supabase Auth по Magic Link. Edge Function проверяет JWT и ID пользователя по приватному белому списку `rpg5_bridge.allowed_readers`. Веб-роль не имеет прямого доступа к таблице пакетов.

Однократно в Supabase Dashboard: Authentication → URL Configuration → Redirect URLs → добавить `https://leoggpentagon-debug.github.io/RPG5-GPT/`.

На сайте в служебном меню нужно войти по почте **существующего** пользователя Supabase Auth. Создание новых пользователей отключено на стороне клиента. Вход и HTTP-тест должны быть подтверждены на реальном браузере.

## Публикация пакета из ChatGPT

Использовать приватный вызов SQL-функции `rpg5_bridge.publish_packet(channel,kind,idempotency_key,payload_text)`. Параметр `payload_text` должен содержать **валидный JSON-объект текстом**, а `kind` — `scene`, `system` или `test`. Функция возвращает номер пакета, SHA-256 и признак повторной отправки.

Повтор с одинаковым ключом и идентичным текстом безопасен. Повтор с другим содержимым отклоняется. Максимальный размер — 1 800 000 байт: больший пакет отклоняется, **никогда не обрезается**.

Рекомендуемый игровой JSON: `{"schema":"rpg5-gpt-packet-v1","reply":{"narration":"...","dialogue":[],"choices":[],"scene_state":{}}}`.

## Запреты и ограничения

В JSON включать только видимые игроку сведения. Закрытые режиссёрские планы, досье, тайны NPC и секретные технические данные не пересылать. Отображение JSON на сайте использует `textContent` и не исполняет HTML.

Передача JSON **не является** постоянным сохранением RPG5. Канон сохраняется исключительно по «сохранить» через `rpg5.commit_scene`.

Канал **не отправляет** сообщения из GitHub Pages в ChatGPT и не открывает автоматически существующий чат с заполненным вводом. Это отдельная задача.

В Supabase размещён технический `kind=test` пакет. Веб-получение после Magic Link ещё требует испытания.
