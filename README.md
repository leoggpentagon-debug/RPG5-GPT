# RPG5-GPT — веб-движок для удалённой игры через ChatGPT

**Режим: GitHub Pages, без постоянно включённого домашнего ПК.**

Сайт скопирован из [RPG6-API](https://github.com/leoggpentagon-debug/RPG6-API), включая оформление, портреты, звуки и элементы игрового интерфейса.

## Что сейчас работает

- Полная статическая оболочка с оформлением RPG6.
- Безопасная изоляция от старой функции `rpg6-gemini`.
- Панель удалённого GPT-подключения с реальной проверкой сервера (когда появится URL шлюза).
- GitHub Pages может публиковать сайт из `main`/`root`.

**GPT-повествование сейчас не работает:** для размещённого в интернете сайта использование подписки ChatGPT Plus через Sign in with ChatGPT не включается автоматически. Необходимо получить разрешение OpenAI, зарегистрированный OAuth client ID и настроить защищённый сервер. В интерфейсе нет фиктивной кнопки входа.

## Что нужно для подключения подписки без платного API

1. Подать заявку: https://openai.com/form/sign-in-with-chatgpt-interest/
2. Получить разрешение на удалённую интеграцию и OAuth client ID с доступом к использованию подписки (сам вход в аккаунт недостаточен).
3. Реализовать приватный backend: OAuth Authorization Code + PKCE, проверку ID token и scopes, защищённые сессии, серверные вызовы Responses API.
4. Настроить доступ к приватной `rpg5` без публикации таблиц или секретов.
5. В `js/config.js` указать **только публичный HTTPS URL** backend в `RPG5_GPT_CONFIG.gatewayUrl`. Все OAuth credentials и секреты должны оставаться вне GitHub Pages.

## Статус и защита

- В `js/config.js` параметры сервера пустые, пока нет одобренного backend.
- `js/app.js` блокирует старые запросы в RPG6 даже при старой конфигурации из браузерного кеша.
- Игра не генерирует ходы и не сохраняет события, пока GPT не подключён.
- `rpg5`, `RPG6-API` и Supabase Edge Functions не изменялись.
