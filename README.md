# RPG5-GPT — сцены через локальное расширение Chrome

**Игровой сайт:** https://leoggpentagon-debug.github.io/RPG5-GPT/

Те же HTML/CSS/JavaScript, портреты, звуки, дневники и игровой движок.
**Доставка** теперь не использует Supabase Auth, серверный API, ссылки на переписки или переходы между вкладками.
Сайт остаётся обычным GitHub Pages. Расширение Chrome Manifest V3 локально переносит JSON из ChatGPT на сайт.

## Один раз

1. Скачай `RPG5_Chrome_Расширение_v1.zip`, распакуй в постоянную папку.
2. Chrome → `chrome://extensions/` → включи «Режим разработчика» → «Загрузить распакованное расширение» → выбери папку с `manifest.json`.
3. Открой сайт и отдельный игровой чат ChatGPT в двух вкладках. В новом проекте размести `GAME_PROJECT_INSTRUCTIONS.md` вместе с действующими механикой и техническим протоколом.
4. В игровом чате сначала попроси «Актуализируй контекст» и **вывести первый полный player-visible JSON**.

## Каждый ход

1. На игровом сайте выбери вариант либо набери действие и нажми **«Отправить»**. Копируется **только действие**, никакого адреса чата.
2. Сам перейди в открытую вкладку ChatGPT, нажми **Ctrl+V → Enter**.
3. Модель выдаёт полный `rpg5-gpt-packet-v1` **в одном ```json-кодовом блоке**. Расширение находит завершённый кодовый блок, отправляет его странице игры и скрывает технический блок после приёма.
4. Сайт проверяет SHA-256 и формат, обновляет сцену, диалоги, персонажей, выборы и дневники. При повторном открытии последняя сцена может быть восстановлена из локального кеша.

**Принципиальное ограничение:** расширение может прочитать только то, что модель реально вывела в HTML ответа. Просто фраза «пакет отправлен», без самого JSON-кодового блока, не доставит сцену. Автоматической отправки *действия* в ChatGPT также нет — ты вставляешь его вручную.

## Приватность и игра

- Расширение работает только на `chatgpt.com` и данном GitHub Pages-сайте и хранит последний игровой пакет в Chrome, без сетевых отправок.
- Секретные режиссёрские поля в пакет не включать.
- Отдельная приватная база `rpg5` в Supabase по-прежнему содержит **канон игры**, и модель может выборочно читать её для механики/сохранения. **Как транспорт JSON Supabase больше не используется.**
- Публикация пакета в браузере не равна сохранению. Сохранение только через буквальное **«сохранить»** и `rpg5.commit_scene`.
- HTML-сайт не загружает `config.js` или старую библиотеку Supabase; старые формы авторизации и ссылки на чаты удалены.
