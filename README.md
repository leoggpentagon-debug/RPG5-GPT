# RPG5-GPT — приёмник JSON из ChatGPT через Supabase

Сайт размещается на GitHub Pages. Домашний компьютер для работы сервера не нужен.

## Реализовано

- Сохранены все прежние HTML/CSS/JS, портреты и звуки.
- Старая RPG6/Gemini функция отключена.
- В Supabase создана **отдельная** приватная схема `rpg5_bridge`, не изменяющая игровой канон `rpg5`.
- Развёрнута функция `rpg5-packet-bridge` — **только чтение**. Она проверяет пользователя через Supabase Auth и приватный белый список ID.
- Сайт раз в 8 секунд, только в открытой вкладке, получает очередной пакет, проверяет SHA-256 и показывает **полный JSON без усечения**. Тестовые пакеты не становятся игровыми сценами.
- Для игровых пакетов поддерживается предварительный вывод `narration`, `dialogue`, `choices`, `scene_state`; произвольные поля не удаляются, весь пакет остаётся в JSON-панели.

## Вход на сайте

В служебном меню укажи почту **существующего** пользователя Supabase Auth и нажми «Получить письмо для входа». Новые пользователи автоматически не регистрируются. Сейчас авторизован только единственный пользователь, имевшийся в проекте до установки канала.

Для работы Magic Link в Supabase Dashboard добавь URL перенаправления:

`https://leoggpentagon-debug.github.io/RPG5-GPT/`

Путь: Authentication → URL Configuration → Redirect URLs. У пользователя должна быть возможность получать письма Auth от Supabase.

## Как Пятница отправляет ответ на сайт

После игрового ответа она записывает **полный player-visible JSON** одной SQL-операцией в `rpg5_bridge.packets` через подключение Supabase. Не режет текст до краткого пересказа. На странице пакет появится автоматически, если ты вошёл через Supabase Auth.

Это **не автоматическая отправка действия из сайта в ChatGPT**. Сообщение по-прежнему нужно отправить в ChatGPT отдельно; сайт лишь получает готовый ответ.

Это **не сохранение канона**: единственным штатным игровым сохранением остаётся `rpg5.commit_scene` по буквальной команде «сохранить».

## Безопасность

`rpg5_bridge` приватна; у `anon`, `authenticated`, `service_role` нет прямого `USAGE` в схеме. SQL-пакеты пишет только подключённая Пятница с приватными правами, а браузер может читать их через авторизованную Edge Function.

Никогда не размещай в GitHub access/refresh токены Auth, секретные ключи Supabase, приватные досье или планы ведущей. Пакет должен содержать **только информацию, предназначенную игроку**.

## Текущие ограничения

- Edge Function активна, схема и SQL-передача подготовлены.
- Реальный вход по Magic Link **ещё не был проверен на твоём аккаунте**; без него сайт не получит ответы.
- Полный HTTP-проход из браузера также требует проверки на твоём устройстве.
- Кнопки выбора ещё не отправляют сообщения в нужный чат ChatGPT автоматически: это отдельная доработка.
