# RPG5-GPT — двусторонняя связь с ChatGPT через Chrome

**Сайт:** https://leoggpentagon-debug.github.io/RPG5-GPT/

Сайт GitHub Pages, локальное Chrome-расширение и игровой чат ChatGPT работают вместе без платного ChatGPT API. Supabase остаётся отдельным хранилищем игрового канона.

## Установка расширения v1.2

1. Распакуй `RPG5_Chrome_Расширение_v1_2.zip` в постоянную папку.
2. Если установлена версия 1.1, открой `chrome://extensions/` → RPG5 → **Сведения** → **Источник расширения**. Замени файлы в прежней распакованной папке и нажми кнопку обновления расширения. Или удали старую версию и загрузи новую папку через «Загрузить распакованное расширение».
3. Обнови **обе вкладки** ChatGPT и сайта с помощью Ctrl+F5.
4. Открой нужный игровой чат ChatGPT, нажми значок расширения и кнопку **«Привязать эту вкладку ChatGPT»**. По умолчанию расширение также автоматически привязывает вкладку, из которой пришёл последний валидный RPG5 JSON; при единственной вкладке ChatGPT может использовать её.
5. Убедись, что поле ввода игрового чата пустое.

## Каждый ход

1. Сайт получает полный player-visible JSON от ChatGPT через расширение и отрисовывает сцену.
2. Нажми вариант или введи произвольное действие на сайте.
3. Сайт формирует сообщение с действием, метаданными сцены и **только отображаемым состоянием** героя: характеристики, инвентарь, вес, навыки, эффекты. Это снимок полученного JSON, а не новая математическая симуляция.
4. Расширение **активирует привязанную вкладку ChatGPT и вставляет сообщение в поле ввода, не нажимая Enter и не отправляя сообщение**.
5. Проверь текст, нажми **Enter вручную**. После получения следующего полноценного JSON игра обновится.
6. Если вставка не получилась, сайт предлагает резервный вариант: **Ctrl+V**. Чтобы не стереть собственный черновик, расширение отклоняет вставку в непустое поле.

## Сохранение

- Кнопка сохранения передаёт **ровно** `сохранить`, без дополнительных блоков или JSON. Нажми Enter вручную.
- Лишь подтверждённая операция `rpg5.commit_scene` в Supabase меняет каноническую игру.
- Получение JSON, локальное состояние, передача действия и автозаполнение поля **не являются сохранением**.

## Ограничения первой версии

- Сайт ещё **не вычисляет** игровую математику самостоятельно — он передаёт точный снимок текущего player-visible пакета. Перенос арифметики на сайт — отдельный этап.
- Здесь нет автоматического отправления сообщений, скрытой работы с ChatGPT API или Supabase.
- Доставка рассчитана на живой HTML-интерфейс `chatgpt.com`; если ChatGPT изменит редактор, может потребоваться обновление расширения.
- Не включать приватные данные NPC/режиссёра в player-visible пакеты.
- Если чат в привязанной вкладке сменился, привяжи нужную беседу заново.

## Автоматический d20 на сайте

При получении валидного `mechanics.pending_d20` браузер самостоятельно генерирует
равновероятное натуральное число 1–20 с помощью `crypto.getRandomValues()`,
считает исход и через расширение готовит ответ в ChatGPT. Ручного ввода числа нет.
Повторное открытие страницы не перебрасывает уже полученное значение.
Если расширение не подтвердило вставку, доступна повторная отправка того же
результата. Нажатие Enter в ChatGPT по-прежнему выполняет пользователь.
Формат: [`docs/rpg5-d20-contract.md`](docs/rpg5-d20-contract.md).
