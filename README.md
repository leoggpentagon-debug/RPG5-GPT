# RPG6 — GitHub Pages frontend

Эта папка содержит статическую клиентскую часть RPG6. Запись событий и вызовы Gemini выполняет Supabase Edge Function, не GitHub.

## Публикация

1. Загрузите **содержимое этой папки** (не папку целиком) в корень репозитория, чтобы `index.html` был на верхнем уровне.
2. В GitHub откройте **Settings → Pages → Build and deployment**.
3. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и сохраните.
4. Перейдите по адресу `https://<username>.github.io/<repository>/`.
5. Нажмите «Продолжить RPG6», затем введите личный код доступа.

Код доступа сохраняется только в `sessionStorage` активной вкладки браузера и не входит в репозиторий.

## Важно

- **Никогда** не загружайте `js/access.js`, ключ Gemini, пароль или ключ Supabase `service_role`.
- Значение `publishableKey` в `js/config.js` специально публичное, но доступ к данным должен защищать сервер.
- Сайт на GitHub Pages обычно доступен всем в интернете — даже при приватном исходном репозитории. Доступ к самой игре требует личного кода RPG6.
- Для GitHub Free публикация Pages доступна из **публичных** репозиториев; для Pages из приватного репозитория нужен поддерживаемый платный план.
- Для релиза лучше проверять совместимость `app.js` с действующей серверной функцией перед публикацией.
