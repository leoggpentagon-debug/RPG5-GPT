# RPG5-GPT — игра 28 DAYS LATER: SURVIVAL через ChatGPT Plus

**Адрес игры:** https://leoggpentagon-debug.github.io/RPG5-GPT/

Новый веб-интерфейс использует оригинальную графику, портреты и звук. Старый RPG6/Gemini код физически сохранён, но **не выполняется**.

## Что уже реализовано

- Из действующей приватной схемы `rpg5` считана текущая сохранённая сцена: **день 37, 13:38, эпизод 2, сцена 63**.
- Опубликован полный игровой JSON, пакет **№3** в `rpg5_bridge.packets`. В нём настоящее состояние Оливера, наблюдаемые NPC, локация, повествование, диалог и 3 работающих варианта действия.
- Edge Function `rpg5-packet-bridge` защищена Supabase Auth + allowlist. Она отдаёт исходный JSON текстом; браузер сверяет SHA-256.
- Сайт отображает сцены через оригинальный сценарный экран `game-ui.js`, панель персонажей и карточку героя; инвентарь и механика берутся из JSON. Данные персонажей для игрока не содержат режиссёрских секретов.
- Работают кнопки подсказок, произвольное действие, сохранение через ChatGPT. Они **готовят и копируют запрос** и открывают настроенную переписку. Никаких платных запросов OpenAI API нет.
- При возвращении с ChatGPT сайт проверяет новые пакеты в Supabase и обновляет сцену. При обновлении страницы последний проверенный пакет может быть восстановлен из кеша текущей вкладки.

## Что сделать один раз

1. На сайте открой служебное меню (☰). Войди через **Supabase Auth**, если ещё не вошёл.
2. Открой **нужную обычную переписку ChatGPT внутри проекта Pussy Boy** в другой вкладке. Скопируй её адрес из адресной строки браузера, например `https://chatgpt.com/c/...` (это **не** публичная ссылка `/share/`).
3. Вернись на сайт, вставь адрес в поле «Адрес переписки в проекте ChatGPT» и нажми «Сохранить адрес чата».

Теперь выбирай действие на сайте. Подготовленный игровой запрос автоматически копируется и открывает именно эту переписку. Мы пробуем подставить текст в поле через `?q=`, **но ChatGPT не гарантирует эту функцию для существующего чата**. Если поле не заполнилось, нажми **Ctrl+V**, затем **Enter**. Вводишь действие только на сайте, вручную передавать JSON не требуется.

После отправки Пятница должна обработать ход и **записать полную видимую игроку часть ответа** через приватный `rpg5_bridge.publish_packet`. После возврата на вкладку игры ответ появляется автоматически через опрос Supabase.

Вся доставка уже работает без локального сервера. **Сам переход и заполнение ввода ChatGPT пока не испытаны в твоём браузере.** Если ChatGPT не поддержит `?q=` для существующего чата, останутся Ctrl+V и Enter.

## Правила сохранения

Транспортный пакет **не** сохраняет игровой канон. Кнопка «Сохранить через ChatGPT» отправляет буквальный текст `сохранить` в подготовленный запрос: реальная запись в `rpg5` производится только через `rpg5.commit_scene` по правилам проекта.

Заблокирован прямой доступ веб-ролей к закрытой `rpg5` и `rpg5_bridge`. Портреты выбираются только из утверждённых файлов; неизвестная внешность не рисуется браузером.
