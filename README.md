# RPG5-GPT — отдельная версия интерфейса для GPT

Исходный интерфейс скопирован из [RPG6-API](https://github.com/leoggpentagon-debug/RPG6-API), включая HTML/CSS/JS, портреты и звуки.

## Текущий статус — отключено до тестирования

- `rpg6-gemini` больше не настроен в `js/config.js`.
- `js/app.js` блокирует **все** старые обращения к RPG6/Gemini, даже если браузер использует старую закешированную конфигурацию.
- При открытии сайта показывается сообщение о подготовке, без загрузки игрового состояния, генерации ходов и сохранения.
- Старые элементы ввода кода RPG6 скрыты, ключи локального хранилища для новой версии имеют отдельное пространство имён.
- **Sign in with ChatGPT пока НЕ подключён.** Сайт сейчас является только визуальной оболочкой.
- Репозиторий `RPG6-API`, функции Supabase и каноническая база `rpg5` не изменяются.

## GitHub Pages

Для публикации: Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)`.

Адрес после включения: https://leoggpentagon-debug.github.io/RPG5-GPT/

## Следующий шаг

Отдельно проверить официальную интеграцию [Sign in with ChatGPT](https://developers.openai.com/siwc/quickstart) на локальном тестовом приложении, не подключая сразу каноническую базу RPG5. Поддержка использования подписки в произвольном удалённом приложении не гарантирована.

Никогда не загружайте в публичный GitHub личные коды доступа, токены OAuth, ключи OpenAI API и Supabase `service_role`.
